# Bearden High Robotics Club

The official website for the Bearden High School Robotics Club.

## Stack

- [Vite](https://vitejs.dev/) + [React](https://react.dev/)
- [Framer](https://www.framer.com/) for design and motion

## Getting started

```bash
npm install
npm run dev
```

## Branches

- `main` — stable
- `rcommits` — active development; all commits land here first
